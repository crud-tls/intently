# Intently Brand Enhancement Plan
## Turning Product into Brand: Actionable Roadmap

---

## Overview

This document breaks down brand enhancement initiatives into actionable tasks with clear owners, timelines, and success metrics.

**Timeline**: Q1 2026 (January - March)
**Goal**: Transform Intently from a functional product into an emotionally resonant brand

---

## Phase 1: Foundation (Weeks 1-4)
### Immediate Wins & Brand Identity

#### Task 1.1: Develop Brand Tagline
- **Owner**: Marketing/Founder
- **Deadline**: Week 1
- **Action Steps**:
  - [ ] Brainstorm 20 tagline options focusing on "pause" and "choice"
  - [ ] Test top 5 with 10 current users via email survey
  - [ ] Finalize tagline
  - [ ] Update homepage hero section with new tagline
- **Success**: Clear, memorable tagline live on site
- **Options to test**:
  - "Pause before you scroll"
  - "Technology, on your terms"
  - "Choose how you use"
  - "Mindful moments, meaningful days"
  - "Your phone. Your choice."

#### Task 1.2: Collect and Display User Testimonials
- **Owner**: Marketing
- **Deadline**: Week 2
- **Action Steps**:
  - [ ] Create testimonial collection form (Typeform/Google Form)
  - [ ] Email current users requesting stories (use your existing user base)
  - [ ] Target: 15-20 quality testimonials with photos
  - [ ] Create testimonials section on homepage
  - [ ] Add testimonial component to features page
- **Success**: 10+ testimonials live on site with real user photos
- **Questions to ask**:
  - "What was your screen time before Intently?"
  - "What's it now?"
  - "What's the biggest change you've noticed?"
  - "How would you describe Intently to a friend?"

#### Task 1.3: Create Brand Guidelines Document
- **Owner**: Design
- **Deadline**: Week 3
- **Action Steps**:
  - [ ] Document current colors with hex codes and usage rules
  - [ ] Define typography scale and usage
  - [ ] Write brand voice guidelines (tone, do's/don'ts)
  - [ ] Create logo variations and usage rules
  - [ ] Add photography/illustration direction
  - [ ] Save as `docs/brand-guidelines.md`
- **Deliverable**: Comprehensive brand guide PDF/website
- **Success**: All future content follows guidelines consistently

#### Task 1.4: Craft Origin Story
- **Owner**: Founder/Content
- **Deadline**: Week 4
- **Action Steps**:
  - [ ] Interview founder about why they built Intently
  - [ ] Write 500-800 word narrative origin story
  - [ ] Include: personal struggle with phone addiction, the "aha moment", early iterations
  - [ ] Add to About page as featured section
  - [ ] Create "Our Story" page if About page is too long
- **Success**: Authentic, emotional story prominently displayed

#### Task 1.5: Add "Join the Community" Social Proof
- **Owner**: Development
- **Deadline**: Week 4
- **Action Steps**:
  - [ ] Add user count badge to homepage hero (e.g., "50,000+ mindful users")
  - [ ] Create live counter component if data available
  - [ ] Add "Used in 150+ countries" if applicable
  - [ ] Add trusted-by logos (publications, app store features)
- **Files to modify**: `src/components/Hero.astro`
- **Success**: Social proof visible above the fold

## Phase 2: Content & Community (Weeks 5-8)
### Building Brand Voice and User Engagement

#### Task 2.1: Launch 7-Day Mindful Tech Challenge
- **Owner**: Content/Marketing
- **Deadline**: Week 6
- **Action Steps**:
  - [ ] Create challenge content (7 daily email lessons)
  - [ ] Day 1: The Awareness Check (track one app)
  - [ ] Day 2: The Pause Practice (set 3 mindful intentions)
  - [ ] Day 3: The Notification Cleanse (turn off non-essentials)
  - [ ] Day 4: The Morning Ritual (phone-free first 30 min)
  - [ ] Day 5: The Evening Wind-Down (no screens 1 hr before bed)
  - [ ] Day 6: The Social Media Audit (unfollow triggering accounts)
  - [ ] Day 7: The Weekly Reflection (review progress)
  - [ ] Create landing page: `/challenge`
  - [ ] Set up email automation (ConvertKit/Mailchimp)
  - [ ] Create challenge completion badge
- **Files to create**: `src/pages/challenge.astro`, email templates
- **Success**: 500+ signups in first month

#### Task 2.2: Build Social Media Presence
- **Owner**: Marketing/Social
- **Deadline**: Week 7 (ongoing)
- **Action Steps**:
  - [ ] Claim handles: @intentlyapp on Instagram, TikTok, LinkedIn
  - [ ] Create content calendar (30 days of posts)
  - [ ] **Instagram content types**:
    - Daily mindful tips (carousel posts)
    - User testimonials (reposts)
    - Behind-the-scenes (team/product updates)
    - Educational infographics
  - [ ] **TikTok content types**:
    - "Phone addiction facts" (trending sounds)
    - Quick tutorials (Intently features)
    - Relatable moments (putting phone down)
    - Before/after stories
  - [ ] **LinkedIn content types**:
    - Thought leadership on digital wellbeing
    - Workplace productivity tips
    - Research-backed insights
  - [ ] Post schedule: 3-4x/week per platform
- **Success**: 1,000+ followers across platforms in 2 months

#### Task 2.3: Create "Stories of Change" Page
- **Owner**: Content/Design
- **Deadline**: Week 7
- **Action Steps**:
  - [ ] Interview 5-10 users for in-depth stories
  - [ ] Write narrative stories with photos
  - [ ] Create `/stories` page
  - [ ] Include: "Your Story" submission form
  - [ ] Format: Q&A style with before/after metrics
- **Files to create**: `src/pages/stories.astro`
- **Success**: 10+ featured stories, steady submissions

#### Task 2.4: Launch Email Newsletter
- **Owner**: Content/Marketing
- **Deadline**: Week 8
- **Action Steps**:
  - [ ] Set up email service (ConvertKit, Mailchimp, or Beehiiv)
  - [ ] Create signup form on website
  - [ ] Name options: "The Mindful Tech Digest", "Intently Insights", "The Pause"
  - [ ] Content format:
    - Weekly mindful tip
    - User spotlight
    - Research snippet
    - App update
  - [ ] Create welcome email sequence (3 emails)
  - [ ] Schedule: Weekly (same day/time)
- **Success**: 1,000+ subscribers in 3 months, 40%+ open rate

## Phase 3: Visual Evolution (Weeks 9-12)
### Signature Brand Elements

#### Task 3.1: Develop Signature Gradient
- **Owner**: Design
- **Deadline**: Week 9
- **Action Steps**:
  - [ ] Create 3-5 gradient options representing "pause," "calm," "transition"
  - [ ] Test with team and users
  - [ ] Finalize gradient as "Intently Sunset" or "Mindful Moment"
  - [ ] Update: hero backgrounds, buttons, cards, social media templates
  - [ ] Document usage in brand guidelines
- **Success**: Distinctive gradient used consistently across touchpoints
- **Color inspiration**: Sunset (purple→orange), Dawn (blue→yellow), Forest (green→teal)

#### Task 3.2: Commission Custom Illustrations
- **Owner**: Design
- **Deadline**: Week 10
- **Action Steps**:
  - [ ] Define illustration style: minimalist, warm, human
  - [ ] List needed scenes:
    - Person pausing before phone
    - Family dinner, phones away
    - Focused work session
    - Peaceful morning routine
    - Achievement/unlock moment
  - [ ] Find illustrator (Dribbble, Instagram, referrals)
  - [ ] Brief and commission 5-10 illustrations
  - [ ] Integrate into homepage, features, blog headers
- **Budget**: $500-2,000 depending on illustrator
- **Success**: Custom illustrations that feel uniquely "Intently"

#### Task 3.3: Add Breathing Animation to Site
- **Owner**: Development
- **Deadline**: Week 11
- **Action Steps**:
  - [ ] Create CSS/JS breathing animation component
  - [ ] Style: Expanding/contracting circle (4 seconds in, 4 seconds out)
  - [ ] Add to: homepage hero, quiz results page
  - [ ] Include text: "Breathe. Pause. Choose."
  - [ ] Make interactive: click to pause animation
- **Files to modify**: `src/components/Hero.astro`, create `src/components/BreathingExercise.astro`
- **Success**: Smooth, calming animation that embodies brand philosophy

#### Task 3.4: Create Photography Direction Guide
- **Owner**: Design/Content
- **Deadline**: Week 12
- **Action Steps**:
  - [ ] Define photography style: warm lighting, authentic moments, diverse subjects
  - [ ] Create mood board (Pinterest reference)
  - [ ] Write shot list for future photoshoots:
    - Morning routine scenes
    - Work/focus moments
    - Social connection (people together, no phones)
    - Achievement celebration
  - [ ] Source stock photos from Unsplash/Pexels that match style
  - [ ] Document do's and don'ts in brand guidelines
- **Success**: Consistent, warm photography across all marketing

### Deepening Brand Connections

#### Task 4.1: Design In-App Encouragement Moments
- **Owner**: Product/Design
- **Deadline**: Week 13
- **Action Steps**:

  - [ ] Write encouraging messages for each milestone

  - [ ] Add "Share your progress" feature
  - [ ] Create milestone badges (3 days, 7 days, 30 days, 100 days)

  - "That's 100 conscious choices. You're building a new relationship with tech."

#### Task 4.2: Create Welcome Email Sequence
- **Owner**: Content/Marketing
- **Deadline**: Week 14
- **Action Steps**:
  - [ ] Write 3-email welcome series:

    - Email 3 (day 4): Your first mindful moment invitation
  - [ ] Design email templates with brand gradient
  - [ ] Set up automation
  - [ ] Test and optimize for open rates
- **Success**: 50%+ open rate, positive replies

#### Task 4.3: Develop Referral Program
- **Owner**: Marketing/Development

- **Action Steps**:

  - [ ] Celebrate top referrers (with permission)

#### Task 4.4: Create Brand Merchandise (Sticker Pack)

## Phase 6: Measurement & Iteration (Ongoing)
### Tracking Brand Health

#### Task 6.1: Set Up Brand Monitoring Dashboard
- **Owner**: Marketing/Data
- **Deadline**: Week 21
- **Action Steps**:
  - [ ] Set up Google Alerts for "Intently app"
  - [ ] Track social mentions (Hootsuite, Buffer, or manual)
  - [ ] Monitor app store reviews weekly
  - [ ] Create monthly brand health report template
  - [ ] Metrics to track:
    - Search volume (Google Search Console)
    - Social sentiment
    - App store rating changes
    - Brand mentions (press, social, blogs)
- **Success**: Monthly reports with actionable insights

#### Task 6.2: Conduct Brand Perception Survey
- **Owner**: Marketing
- **Deadline**: Week 22, then quarterly
- **Action Steps**:
  - [ ] Create survey with questions:
    - "What 3 words would you use to describe Intently?"
    - "How does Intently make you feel?"
    - "What's our biggest strength/weakness?"
    - "Would you recommend Intently? Why/why not?"
  - [ ] Send to user email list
  - [ ] Offer incentive (exclusive feature, merchandise)
  - [ ] Analyze results and create action plan
- **Success**: Baseline established, improvements tracked quarterly

#### Task 6.3: Monthly Brand Strategy Review
- **Owner**: Leadership team
- **Frequency**: Monthly
- **Action Steps**:
  - [ ] Schedule 1-hour monthly review
  - [ ] Review metrics: users, engagement, sentiment
  - [ ] Assess what's working/not working
  - [ ] Adjust priorities based on data
  - [ ] Document decisions and next steps
- **Success**: Agile brand strategy that evolves with feedback
